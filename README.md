## What is RedCircle?

RedCircle lets anyone tokenize a Reddit post as an SPL token on Solana. The original post creator earns USDC, curators get rewarded, and anyone can trade on Jupiter DEX.

## How it works

1. Paste a Reddit post URL into the Mint Terminal
2. Server pays the gas — no SOL needed to launch
3. Token goes live on Solana via a Meteora liquidity pool
4. Trade instantly on Jupiter DEX

## Fee model

**2% on every buy and sell**

| Recipient | Fee |
|-----------|-----|
| Creator (original post author) | 0.40% — claimable as USDC |
| Curator (launcher) | 0.15% — claimable as USDC |
| RedCircle | 0.50% |
| Protocol (Meteora + Orynth) | 0.95% |
