# Glossary

| Term         | Definition                                                                                          |
| ------------ | --------------------------------------------------------------------------------------------------- |
| Red post     | A tokenized post (Reddit or X) on RedCircle — the SPL token (with the `red` suffix) that represents a specific social post. |              |
| Mint address | The unique on-chain identifier for a token. Used to look it up via the Partner API or any Solana explorer. |                                     |
| Creator      | The original author of a tokenized post (Reddit or X); earns 0.40% of every trade.                  |
| Curator      | The person who launches/surfaces a post; the registered wallet earns 0.15% of every trade.          |
