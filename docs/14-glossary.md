# Glossary

| Term         | Definition                                                                                          |
| ------------ | --------------------------------------------------------------------------------------------------- |
| Red post     | A tokenized Reddit post on RedCircle — the SPL token (with the `red` suffix) that represents a specific Reddit post. |                     |
| Mint address | The unique on-chain identifier for a token. Used to look it up via the Partner API or any Solana explorer. |                                     |
| Creator      | The original Reddit author of a tokenized post; earns 0.50% of trades.                              |
| Curator      | The person who launches/surfaces a post; earns a registered share of fees.                          |
