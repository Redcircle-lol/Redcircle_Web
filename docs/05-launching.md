# Launching a token

Launching tokenizes a Reddit or X post into a tradeable market. The entire on-chain cost is covered by RedCircle, and the transaction is signed server-side — you never pay gas or sign a launch transaction yourself.

## 1. Pick a post

Choose a post from the feed or paste a Reddit or X post URL into the launchpad on the [home](/home) page.

## 2. Name your token

RedCircle uses AI (Gemini) to suggest a catchy token name and ticker based on the post's content. You can accept the suggestion or edit it. Symbols are short and punchy; tokens carry the `red` suffix.

## 3. (Optional) Register a curator wallet

Add a Solana wallet address to claim curator rewards for surfacing this post. This wallet is locked to the launch and is the only one that can later claim the curator share.

## 4. Confirm

RedCircle prepares the launch with Orynth, signs as both pool creator and payer, and submits it on-chain. Within seconds the token is minted, a Meteora pool is created, and the token appears in the feed.

> **Note:** Each post (Reddit or X) maps to exactly one token. If a post has already been launched, you'll be pointed to the existing market instead of creating a duplicate.
